# Sportify Frontend

Sportify is a responsive sports platform built with **React.js** that allows users to explore sports news, browse merchandise, book tickets, watch videos, and manage their profile.

## Features

- User Authentication
- Sports News
- Merchandise Store
- Shopping Cart
- Ticket Booking
- Match & Event Listings
- User Profile
- Admin Dashboard
- Responsive Design

## Tech Stack

- React.js
- JavaScript
- CSS3
- React Router
- Axios
- Vite

## Getting Started

```bash
npm install
npm run dev
